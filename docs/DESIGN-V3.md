# Shakers — dirección editorial v3

La referencia del usuario aporta composición narrativa, collage fotográfico, papel y detalles artesanales. La portada aplica estos recursos a amistad, música y fe con una base marfil, púrpura, turquesa y coral.

Cambios: portada con imagen sin texto y contenido HTML accesible; bienvenida con tres accesos; tarjetas de color; sección Somos Shakers con fotografía enmarcada; cierre púrpura/lima. El arte de portada mantiene su base clara en ambos temas; navegación y páginas internas conservan su selector de tema.

Imagen generada con imagegen integrado: `public/branding/shakers-v3/collage-original.png`. Prompt exacto: `public/branding/shakers-v3/prompt.txt`. Versión web: `public/images/shakers-collage-v3.webp`. Las personas son ficticias e ilustrativas, no integrantes reales. Los diseños anteriores permanecen disponibles.

Se conserva la lógica de datos y autenticación. Esta iteración establece la dirección visual en la portada; quedan por personalizar las fotografías reales, identidad definitiva, contenidos y adaptación editorial de las pantallas internas. Sin publicación ni conexión a servicios externos.
